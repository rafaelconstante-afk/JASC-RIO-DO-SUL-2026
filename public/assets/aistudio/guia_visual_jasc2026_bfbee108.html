Como capturar o design verdadeiro da página

  1. Abra o site original no Chrome ou Opera, no Mac.
  2. Pressione Command + Option + I para abrir as ferramentas de desenvolvedor.
  3. Pressione Command + Shift + P e digite Capture full size screenshot.
  4. Salve a captura inteira da página inicial.
  5. Ative o modo mobile com Command + Shift + M, defina 390 × 844 e repita.
  6. Repita em Programação, Modalidades, Locais, Notícias e Resultados, quando acessíveis, e anexe os PNGs à IA.

Prioridade para a IA

1. Capturas de tela do site original: referência definitiva de layout e tipografia. 2. Imagens originais dos links desta página: recursos gráficos a preservar. 3. ZIP da recriação inicial: base de código a corrigir. 4. Site publicado: referência interativa para menus e funcionalidades. Proibido redesenhar. Comparar sempre a implementação com as capturas originais nas mesmas resoluções.
