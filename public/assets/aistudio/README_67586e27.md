# Portal JASC 2026 — recriação independente

**Aviso:** este pacote NÃO é o código-fonte original gerado pelo Lovable. É uma reconstrução independente, feita a partir das informações públicas de `https://pixel-perfect-picture-match-168.lovable.app/` em 10/11/2026.

## Abrir e editar

1. Descompacte o arquivo `.zip`.
2. Abra `index.html` no navegador. Não exige instalação nem terminal.
3. Edite `index.html`, `styles.css` e `app.js` no VS Code ou em outro editor.

### Conteúdo

- Página inicial e menu responsivo.
- Programação com seleção de dias e filtros funcionais.
- Páginas de modalidades, locais, notícias, resultados e detalhes das atividades.
- Painel de demonstração (`#/admin`), com inclusão/exclusão local e exportação em JSON.
- Layout responsivo com links por hash, acessibilidade básica e ajuste de movimento.

### Limitações

- Os arquivos de imagem e as fontes apontam para os serviços remotos do site informado / Google Fonts. Se esses serviços mudarem ou saírem do ar, as imagens poderão deixar de aparecer. Para usar offline, baixe arquivos autorizados e ajuste os caminhos em `app.js`.
- O visual é inspirado no site, **não uma cópia pixel a pixel**.
- Parte da programação e dos locais é **demonstrativa**, não é calendário oficial.
- Não existe banco de dados ou servidor; o painel administrativo usa apenas `localStorage` deste navegador. Não deve ser publicado como painel real de gestão.
- Algumas páginas do site original não puderam ser consultadas diretamente a partir da URL pública; nesta recriação foram implementadas usando os conteúdos da página inicial.

## Como obter o código-fonte original, sem reconstrução

Acesse a conta responsável pelo projeto em https://lovable.dev e abra o projeto. Use o editor de código do Lovable (quando disponível) ou a integração com GitHub para sincronizar/exportar o repositório. É o caminho para obter os componentes React, estilos, configurações e eventual integração de backend exatamente como foram criados. Um URL público `*.lovable.app` não fornece os arquivos-fonte originais do editor.
